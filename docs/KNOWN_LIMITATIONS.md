# Known limitations (read before trusting any number)
1. **In-distribution benchmark.** Train/val/test come from the same synthetic generator (different programs, same style). The hand-written corpus (n=18) is too small for statistics: the compiler is already right on 16/18; **all three strategies miss `c-struct-semi`** (truth 4, all pick 6) and the rule engine also misses `cpp-class-semi`. ML 94.4% vs rule/compiler 88.9% there is 1 case.
2. **Single injected error.** Only the first compiler error is localised; real files may have several. Semantic errors are reported but not localised.
3. **Missing `}` is the weak spot:** ML 64.1% top-1, rule 41.0%, compiler 0% (test split). For real code the "right line" of a missing brace is ambiguous.
4. **Category accuracy is 68.7%** (Java 58%, Python 53%): a message-pattern classifier, not ML; several injected kinds surface as generic "invalid syntax".
5. **Java:** javac already reports a missing `;` at the right line (no headroom). Dataset generation compiles Java in one batch with the class renamed `C<i>`; columns on the class line can shift (lines cannot).
6. **Execution is not sandboxed.** rlimits, timeout, 64 KB output cap, scrubbed env, temp dir and a no-network namespace apply, but there is no filesystem/PID isolation (no docker/bwrap here), so untrusted code could read host files. `/api/run` is therefore **off by default**. Compile-only checks reject path-traversing includes (`#include "/etc/passwd"`), and Python is parsed, never run. Do not expose the server to untrusted users without a container/VM boundary.
7. The model is a joblib pickle: load only models you trained. Retrain after editing `features.py` (version-checked).
8. ~~FastAPI app and React frontend were never executed~~ - as of the Counterfactual Repair Lab work, both now have been: `pip install fastapi uvicorn httpx` and `npm install && npm run build` succeed in this environment, `npx tsc --noEmit` is clean, and the built `frontend/dist` was served live by `backend/simple_server.py` and exercised end-to-end (`/api/health`, `/api/diagnose`, `/api/counterfactual`). Python analysis still uses CPython `compile()` for the verdict and a custom tolerant lexer (not `tokenize`) for features.
9. Same-seed dataset regeneration should reproduce the data (RNGs seeded, generator determinism unit-tested), but a byte-for-byte rerun was not diffed.

## Counterfactual Repair Lab (added - see docs/COUNTERFACTUAL_REPAIR_LAB.md)
10. **Compiling is not correctness.** A candidate patch that makes the file compile is evidence it is *a* valid fix, never proof it is *the* programmer's actual mistake - measured **false-correction rate is 9.4%** on the n=40 benchmark subset (see BENCHMARK_REPORT.md "Strategy D"). The UI and API expose `ambiguous`/`verified_lines` for exactly this reason; callers should not treat the top-ranked line as certain.
11. **Strategy D metrics are on a smaller, compile-validated subset (n=40 at the shipped `suggestion_limit=10`), not the full 489-sample held-out split**, because unlike rule/ML ranking, counterfactual validation actually invokes the compiler per candidate patch (avg. 2.1s/sample here, dominated by `javac`). Do not directly compare its Top-1 (92.5%) to the full-split ML Top-1 (97.1%) - on the SAME n=40 subset ML actually scores 97.5% and rule 92.5%, i.e. the counterfactual layer ties rule-based and trails ML on this run; it adds verified/false-correction evidence ML and rule-based cannot provide, it does not establish that it localises better.
12. **`heuristic_score` is not a probability.** It is `composite / max(composite)` for display scaling only; composites are not renormalised to sum to 1, unlike the rule and ML strategy scores. Do not average or compare it across requests.
13. **Bounded by design.** Each request compiles at most `cf_max_lines × cf_patches_per_line` (default 6×3=18, capped at 12×6=72) candidate patches. A real root cause outside that window, or requiring a multi-token edit no existing `patches_for_line` template produces, will not be found - it falls back to "not validated", not a false negative claim.
